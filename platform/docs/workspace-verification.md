# Agent 工作空间实施与验收记录

日期：2026-10-27。范围仅为独立 `platform/`；外层 MCPHub 工作区改动保留。当前单进程部署提供应用权限、凭证和运行会话隔离，不新增系统账号、容器或文件系统沙箱。

## 五阶段实现

| 阶段             | 实现与边界                                                                                                                                                                               | 验证入口                                                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 1 数据与权限     | 服务端 ExecutionContext；AccessService 合并长期与当前主体临时授权；Profile、绑定和连接修订号；目录、工具、Prompt、Resource/模板、订阅、交互、Apps、产物均重新鉴权                        | workspacePermissions、catalog、interactions、apps、openapi |
| 2 身份与工作空间 | 每 Profile/连接支持 inherit/profile/credential；OAuth、独立加密 HTTP/OpenAPI 凭证、声明的 stdio 环境变量；缺失身份凭证明确失败；专属身份跨入口稳定，运行会话分离；切换和绑定撤销影响预览 | workspaceIdentity、upstreamOAuth、sessionIsolation、pi     |
| 3 任务与诊断     | TaskStore 事务快照、输出检查点和单调修订；调用的 Profile/任务/入口/凭证/绑定/连接/设备/关联 ID；任务详情关联交互、Apps、产物；刷新读取快照，重启标记未知并结束视图，不重放               | workspaceHandoffs、apps、interactions；本地 Chrome         |
| 4 临时权限       | requestable 与长期授权分开；事务子集审批、默认一小时、幂等；外部凭证/Pi 任务作用域；Pi 等待不占业务网络超时，无隐式审批等待上限；批准后刷新工具集，业务需新调用                          | workspacePermissions、apps、interactions、upstreamOAuth    |
| 5 主动交接       | 用户摘要和选定产物；预览/保存/显式执行分离；执行重新校验并事务预留唯一任务；外部凭证归属；鉴权产物入口；无模型保存导出，执行保留真实失败；新任务可按授权读取产物字节区间                 | workspaceHandoffs；本地 Chrome；部署检查                   |

迁移由 Drizzle 生成：0005 增加工作空间、修订、申请、授权、交接与事件；0006 增加绑定与连接修订号，用于核对申请与临时授权保存的身份指纹。未手工编辑生成迁移。旧 Profile 省略新增字段时保留 requestable 和 connectionIdentities，旧字段保持既有读写语义。

修改 Profile、连接及独立固定凭证支持修订冲突检测。OAuth 发起/完成重新授权、本地撤销及固定凭证替换会改变绑定修订，旧身份申请与临时授权不能转移；OAuth access token 常规刷新保留同一 grant/绑定。Profile 切换关闭自己的运行上下文，不撤销其他 Profile 的共享授权。已派发操作可能不可撤回；取消/断线记录未知，不宣称回滚。

新增覆盖以下行为：

- 两个 Agent 的独立 OAuth、HTTP 凭证及真实 stdio 环境；跨入口绑定稳定，轮换凭证保持应有隔离，配置不泄露明文；重新授权使原等待申请失效。
- requestable 批准前不可执行；批准子集、拒绝、取消、显式截止、到期、重复及并发审批；外部 MCP 创建申请后必须新调用；凭证不能共享临时授权。
- 撤销取消依赖授权的调用、订阅、App 和交互续传，不重放；重复长期授权仍有效的运行调用不受误伤；模板与 Prompt 使用同一权限服务。
- 任务重启中断等待，原任务作用域不复活；外部凭证授权仍保留至原截止；输出检查点合并文本增量并暴露写入错误。
- 交接预览后的目标修订变化、外部凭证归属、内容来源、并发幂等执行、无模型失败记录；外部产物下载鉴权；Pi 产物读取与任务结束后的收回。

每个后端 Vitest 进程由 `scripts/test.mjs` 以 **60 秒硬超时**运行，六组顺序执行，无自动重试。真实 Pi 桥接及 Go 单元测试同样使用 60 秒硬超时。

实现期修复：管理静态事件流被动态详情路由遮蔽；旧客户端省略新字段时的兼容写入；审批等待的取消竞态；调用缺省能力造成额外运行会话；输出检查点写入失败的持久状态；OAuth 测试结束前释放长连接。一次开发服务并行运行期间 Apps 夹具返回非 MCP 404，停止开发服务后专项通过；不能据此断言该现象的根因。Pi 父进程断开后的 IPC 发送错误现在显式记录并取消待处理请求，不以成功响应替代。
