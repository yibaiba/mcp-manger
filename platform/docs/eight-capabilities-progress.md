## 第一阶段验证

隔离工作区类型检查、lint 和 145 项后端测试通过，每个测试进程硬超时 60 秒。真实 direct、Pi 和 Go 连接器验证进度续期、总期限、取消与恢复；Go 全包测试与 vet 通过。设备端截止时间先到的竞态通过结构化 `RESULT_UNKNOWN` 保留执行结果不确定性，失败调用不重放。

amd64、arm64 应用镜像构建通过。两种架构的真实 Python 3.13.9 MCP 都完成 direct/Pi 初始化、发现和调用，覆盖冷缓存联网和热缓存禁网，进程为 UID 1000。ARM64 在本机 amd64 仿真中验证；发现并移除嵌入式 Pi 适配器独立 30 秒初始化等待，改由连接预算取消。仿真集成显式设置 600 秒连接期限，后端单测进程仍为 60 秒。

全新 Compose 数据库、重复迁移、登录/API/静态页、禁网 pnpm、真实 Go HMAC 通道重连/重配/撤销、真实无模型 Pi 和 Apps HTTP/CSP 契约通过。Chrome 验证设置保存、非法续期配置提示、恢复状态、桌面和移动布局；Apps 双层 opaque origin、父页面 DOM/Cookie/storage 隔离和工具调用回归通过。截图已上传 PR #4 并确认显示。
