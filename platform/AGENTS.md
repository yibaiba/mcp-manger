# MCP Platform — 独立项目维护说明

`platform/` 是独立应用项目，不是外层 MCPHub 的子模块或功能目录。当前仅由外层 Git 仓库跟踪文件。

- 在本目录运行 pnpm；使用本目录的 `package.json`、`pnpm-workspace.yaml` 和 `pnpm-lock.yaml`。
- 应用代码、共享包、Pi 集成和 Go 设备连接器都属于本项目。不要从外层 MCPHub 导入源码、依赖、配置或数据库实体。
- 环境配置使用本目录的 `.env`，迁移使用 `packages/db/`，运行数据使用本项目配置的数据目录。不要复用旧 MCPHub 的配置或数据。
- Docker Compose 和 Dockerfile 的构建上下文是本目录；复制本目录即可构建和部署。
- 外层 MCPHub 可以作为协议实现参考。迁移实现应落在本项目内，配置导入必须经过本项目的校验和授权流程。
- 修改和提交仅包含当前任务涉及的本项目文件；保留外层项目的工作区改动。

验证命令见 [README](README.md)。后端每个单元测试进程的硬超时为 60 秒。真实设备、供应商授权和模型任务未实测时，必须明确记录，不能用夹具结果代替实机验收。
